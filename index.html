天气不配合，饭也不稳定，但人总得想办法活下来。

Update Guide

以后怎么继续更新

我已经把结构做成适合 GitHub Pages 的静态站了。

01

放证据

把 Peter Xu 的照片放进 `photos/` 文件夹，比如 `photos/runway-sunset.jpg`。

02

加一句吐槽

打开 `script.js`，在最上面的 `photoEntries` 和 `journalEntries` 里继续追加天气、训练和吃饭的记录。

03

长期存档

把文件上传到仓库，开启 GitHub Pages，这份圣乔治生存记录就能长期在线访问。
